  <action>Add three functions after the existing loadAssignment() function:

   - Fetches from GET /api/guest/${guestId}/wishlist
   - Handles 404/429/other errors with showError() or inline message
   - On success, sets textarea value to result
   - Calls updateCounter() to sync character count
   - Handles empty string (no wishlist set) by leaving textarea empty

2. saveWishlist(): Async function that:
   - Gets current textarea value
   - Validates length <= 500 (client-side check before API call)
   - Shows "Saving..." on save button while loading
   - Fetches PUT /api/guest/${guestId}/wishlist with text in body
   - On success: Shows "Wishlist saved!" in message div for 3 seconds then clears
   - On error: Shows error message in message div
   - Re-enables save button after request completes

3. updateCounter(): Function that:
   - Gets textarea value length
   - Updates charCounter text to "${length}/500"
   - Optionally colors counter red when approaching 500 chars (e.g., >450)

Add event listeners at the bottom of guest.js:
- Call loadWishlist() after displayAssignment() in loadAssignment()
- Textarea oninput → updateCounter()
- Save button onclick → saveWishlist()</action>
