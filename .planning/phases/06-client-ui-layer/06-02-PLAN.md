# Gap Sources

**Gap 1: Save Request Mismatch**

- Frontend sends `Content-Type: text/plain;charset=UTF-8` with plain text body
- Backend expects JSON via `request.json()` at line 193 of src/index.ts
- Impact: Save requests fail with JSON parsing error
- Fix: Send JSON.stringify({ wishlist: text }) with Content-Type: application/json

**Gap 2: Load Response Mismatch**

- Frontend reads plain text via `response.text()` at line 52 of public/guest.js
- Backend returns JSON.stringify({ wishlist }) at line 246 of src/index.ts
- Impact: Load requests display raw JSON string in textarea
- Fix: Parse JSON via response.json() and extract data.wishlist
