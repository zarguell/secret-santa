## Implementation Notes

The implementation uses a hybrid approach:

1. **Production**: Uses `env.ASSETS.fetch()` to serve static guest.html from Cloudflare Workers assets
2. **Testing**: Falls back to inline HTML when `env.ASSETS.fetch` is not available
3. **Validation**: All routes validate guest ID format and existence before serving HTML

This ensures the code works in both production (Cloudflare Workers) and testing environments (Vitest).
