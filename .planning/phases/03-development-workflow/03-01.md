## Workflow Documentation

### Single Dev Branch Pattern

1. **Development**: All work happens on `dev` branch
2. **Testing**: Run `npm test` before committing
3. **Deployment**: Deploy `dev` branch for testing
4. **Merge**: Merge `dev` to `main` when stable
5. **Production**: Deploy `main` branch to production

### Commands

```bash
# Switch to dev branch
git checkout dev

# Make changes and test
npm test

# Commit changes
git add .
git commit -m "description"

# Deploy dev branch
wrangler deploy --branch dev

# Test deployed environment
curl https://dev-secret-santa.workers.dev

# Merge to main when ready
git checkout main
git merge dev

# Deploy main to production
wrangler deploy
```
