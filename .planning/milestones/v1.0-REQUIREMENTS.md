# Requirements: v1.0 MVP

## User Stories

### Party Organizer

As a party organizer, I want to:

- Create a Secret Santa event with my party's details
- Get a unique shareable link for my party
- Share this link with guests so they can join
- View who has joined the party

### Guest

As a guest, I want to:

- Join a Secret Santa party using the organizer's link
- Enter my name to participate
- View my Secret Santa assignment (who I'm buying a gift for)
- Access my assignment at any time using my unique link

## Functional Requirements

### Party Creation

- [x] Party organizer can create a party with name, date, and spending limit
- [x] Party gets a unique party ID (UUID)
- [x] Party gets a shareable URL (domain/party/[partyId])
- [x] Party organizer can view their party details and guest list

### Guest Registration

- [x] Guests can join a party via the shareable URL
- [x] Guests provide their name to register
- [x] Each guest gets a unique guest ID (UUID)
- [x] Guest to party ID mapping is stored in KV for fast lookup

### Assignment Generation

- [x] Organizer can trigger assignment generation
- [x] Algorithm ensures no guest is assigned to themselves
- [x] Algorithm ensures each guest has exactly one recipient
- [x] Assignments are stored in the Durable Object's party state
- [x] Each guest can view only their own assignment

### Assignment Viewing

- [x] Guests can view their assignment using their unique guest link
- [x] Guest link is: domain/guest/[guestId]
- [x] Link returns party details and their assigned recipient
- [x] Assignment viewing is served as static HTML page

## Technical Requirements

### Infrastructure

- [x] Single Cloudflare Worker handling all HTTP requests
- [x] Durable Objects for stateful party storage
- [x] KV namespace for fast guest ID lookups
- [x] Static file serving for guest HTML pages
- [x] All serverless, edge-deployed

### Testing

- [x] Vitest test framework set up with Cloudflare Workers compatibility
- [x] Tests for utility functions (assignment generation, etc.)
- [x] Tests for API endpoints (party creation, guest registration, assignment viewing)
- [x] Tests for Durable Objects behavior (state management, KV integration)
- [x] At least 80% code coverage
- [x] All tests passing

### Code Quality

- [x] TypeScript for type safety
- [x] Clear separation of concerns (handlers, storage, utilities)
- [x] Error handling for edge cases (party not found, guest not found)
- [x] Input validation (party name, guest name)

## Non-Functional Requirements

### Performance

- [x] Guest assignment loading < 500ms
- [x] Party creation < 1 second
- [x] Guest registration < 500ms

### Security

- [x] Guests can only view their own assignment
- [x] Party organizer can only view their own party
- [x] Guest IDs are random UUIDs, not guessable

### Reliability

- [x] All state persisted in Durable Objects
- [x] KV used for fast lookups without hitting DO every time
- [x] No data loss on Worker restarts

## Out of Scope

### Email Notifications

Email notifications for party invitations and assignment reveal are not included in v1.0. Users share links manually.

### Wish Lists

Guests cannot add wish lists or see their recipient's wish list. This is out of scope for initial goals.

### Party Editing

Organizers cannot edit party details after creation. Parties are create-only.

### Guest Management

Organizers cannot remove guests or re-generate assignments after initial generation.
